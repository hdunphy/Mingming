# SFX sources

Every file in `public/sfx/` and where it came from. Packs: Sidearm Studios *Ultimate Sound FX Bundle - HD Remaster* (Unity Asset Store, licensed to hdunphy15; usable outside Unity per the Asset Store EULA, not redistributable as loose files), Sonniss *GDC 2026 Game Audio Bundle* (royalty-free, no attribution), Kenney (CC0). Layered clips list every layer. Cut with ffmpeg: leading silence trimmed, faded, peak-normalised to -1 dBFS.
