# Ticket 176f: how long is a run on the new map?

**Short answer.** On the new map the walker fights **11.6 times before the gym** when it skips every detour. That counts the fight on the start node, which the walker has always fought and which the game now fights too (Henry's ruling of 2026-10-03, see "The start-node fight" below); without it the figure is 10.6. The ruled target for that number is **8 to 10**, so it lands above it. With the three gauntlet fights added it is **14.6**, against a target of 10 to 13. Taking every detour adds one fight per biome: 12.6 before the gym, 15.6 with the gauntlet. Nothing was changed to make the numbers fit. Henry's answer on 2026-10-03 was to keep the length as it is for now ("we might need to make it longer"), so the one-row cut at the bottom is not being made.

**Read the sample sizes before the numbers.** The ticket asks for 12 starters × 30 seeds per setup. The sandbox this was run in plays about one walk a minute, and three starters (ratatoskr_v2 and both huldra) take over two and a half minutes a walk, so the sample here is **9 starters × 2 seeds = 18 walks per setup** (the same 18 seeds on all three fights-per-run setups). That is enough for the fight counts, which barely vary between seeds (the map decides them), and not enough for the win rates or the scrap curve, which are marked "thin" below. The commands for the full run are at the bottom; it should be run once on your machine.

## 1. The map's own length (no walker, 500 maps)

Counting only the nodes that are fights (wild, rival, elite, alpha, ambush), on every route from the start to the gym, over 500 generated maps. Events are not counted as fights. Every plain route is 11 nodes long before the gym; what varies is how many of them are events.

| route | mean | fewest | most |
|---|---|---|---|
| detours skipped, the route with the **fewest** fights | 8.4 | 4 | 11 |
| detours skipped, the route with the **most** fights | 10.8 | 9 | 11 |
| every detour taken, fewest | 9.1 | 5 | 11 |
| every detour taken, most | 13.0 | 10 | 14 |

So a player who goes looking for fights meets about 11 before the gym, and one who steers toward events meets about 8. The walker prefers fights, so it sits near the top of that range.

## 2. Fights before the gym (ghost walk, 18 walks per setup)

170a's ghost walk: a fight lost on the way is carried on as a win, so every walk reaches the gym and fights are measured on every run. Same 18 seeds in every column (9 starters × seeds 0 and 1). "Parent" is the commit before ticket 176 (`aaba91f`), "new, skip" is this branch with every detour skipped, "new, take" is this branch with `takeDetours` on.

| fights before the gym | parent | new, skip | new, take |
|---|---|---|---|
| biome 0 (mean, fewest-most) | 3.8 (3-5) | 5.7 (5-6) | 6.2 (5-7) |
| biome 1 | 3.6 (3-5) | 3.9 (3-4) | 4.3 (4-5) |
| biome 2 | 2.7 (2-3) | 1.9 (1-2) | 2.1 (1-3) |
| **total** | **10.1 (8-12)** | **11.6 (11-12)** | **12.6 (11-14)** |
| total without the start-node fight | 9.1 | 10.6 | 11.6 |
| with the three gauntlet fights | 12.1 | 13.6 | 14.6 |

The parent number is the walker's, which never goes back to farm; the 18 to 20 fights in the playtests that started this ticket came from people re-fighting wilds, which one-way travel now rules out. So the right comparison for the new map is not "18 down to 11" but "the walker's 10.1 on the old map up to 11.6 on the new one".

Won in these walks, wild and elite fights (ghost-carried losses included as played): parent wild 90 of 111 (81%), elite 21 of 49 (43%); new skip wild 112 of 120 (93%), elite 29 of 56 (52%); new take wild 120 of 127 (94%), elite 30 of 55 (55%). The new map's wilds are won more often; I have not looked into why, and the sample is thin.

## 4. Verdict

- **Detour-free fights before the gym: 11.6** including the start-node fight (10.6 without it), against the ruled **8 to 10**. Above it. The map itself allows 8 to 11 route fights plus the start.
- **With the gauntlet: 14.6**, against **10 to 13**. Above it.
- **With every detour taken: 12.6 and 15.6**, one more fight per biome as designed. A player who takes every detour is above the run length target, and that is a choice they make.

If the plain run is ever wanted inside the target, the smallest change in the M1 widths is **one fewer route row**: any single route row removed takes one fight off every path, giving about 10.6 before the gym and 13.6 with the gauntlet (still over by the start fight). The cheapest one to lose is biome 0's second route run (the 2-wide row after the town, before the biome's elite): biome 0 is the longest on purpose, but it is also where this walker already fights 5.7 times against 3.9 and 1.9 in the other two. I have not changed it.

## The start-node fight (ruled 2026-10-03)

The walker fights the node it starts on: biome 0's first fight in every walk, parent and new, is on the start node `b0l0n0`, before the first step. The game did not (it drew the start as a flag and opened on the map), so the walker and the game differed by one fight. **Henry ruled on 2026-10-03 that the walker is right and the game was the bug:** a new run now opens straight into the start node's fight (`openingFight.ts`, the scripted easy opening). So the first total in the table in section 2 (10.1 / 11.6 / 12.6), the one that includes the start-node fight, is the number a player now meets; the "without the start-node fight" row is for reference only.

## How to run the full measurement

Same script on both trees (`src/debug/balance/runMapMeasure176.ts` is in this branch; copy it into a checkout of `aaba91f` for the parent arm, where `--detours` is ignored). Each command writes a JSON of one row per walk and can be stopped and restarted (it skips walks already in the file).

```
npx vite-node src/debug/balance/runMapMeasure176.ts -- --paths 500
npx vite-node src/debug/balance/runMapMeasure176.ts -- --kind ghost --detours false --seeds 30 --out ghost-skip.json
npx vite-node src/debug/balance/runMapMeasure176.ts -- --kind ghost --detours true  --seeds 30 --out ghost-take.json
npx vite-node src/debug/balance/runMapMeasure176.ts -- --kind scrap --seeds 30 --out scrap.json
npx vite-node src/debug/balance/runMapMeasure176.ts -- --report ghost-skip.json
```

Seed labels are `ghost176:<starter>:<i>` and `scrap174:<starter>:<i>`; `--starters a,b` and `--from`/`--to` pick a slice. About an hour per file on a laptop; the scrap walk on the parent tree may need a time limit per walk.
