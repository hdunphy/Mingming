# Steam Release — Wayfinder Map

Label: `wayfinder:map` · Branch: `steam-release-prep` · Charted 2026-08-21

**Tracker conventions (local-markdown, same as deck-archetypes):** tickets are files in [`tickets/`](tickets/). Each carries `Type` (`wayfinder:research|prototype|grilling|task`), `Status` (`open|closed`), `Assignee` (blank = unclaimed), `Blocked by` (links, including cross-wayfinder ones) and `Phase`. A session claims a ticket by writing its name into `Assignee` before working. The **frontier** is every ticket that is open, unblocked (all Blocked-by closed) and unclaimed. Resolutions go in the ticket's `## Resolution` on close and are gisted under **Decisions so far**. **One ticket per session.**

## Destination

Mingming is on sale on Steam — a shipped desktop build of the ruled game (expedition roguelike: three biomes (mono-element at EA launch; two-element biomes deferred until more types ship), an explorable region graph, 1→2→3 recruiting into a shared deck, a three-fight no-heal gauntlet, a persistent ranch fed by consumable blueprints, no leveling) with a store page, achievements, cloud saves, a demo that has been through Steam Next Fest, and at least **10 Steam reviews** within the first months. **Release shape RULED: Early Access** ([Release shape](tickets/05-release-shape.md), Henry 2026-08-21) — entry bar: Fire/Water/Nature, 3 mono biomes, 6 species / 12 decks (Air stretch), 3 authored gym leaders, 3 tiers, $4.99–7.99 → $9.99 at 1.0. Success, per Henry (2026-08-21): *shipped + 10 reviews*; PvP is not part of it.

### Why the recommendation is Early Access

Henry has ~5–15 focused hours a week plus heavy agent time, a fourth child arriving, and a $0–500 art budget. Three numbers drive the call. (1) The content ladder the design already chose — tiers, more biome pairs, more gyms, enemy Drivers, run modifiers — is exactly what Early Access is for: the loop ships complete and the ladder grows in public. (2) Steam's 10-review bar and the algorithm's first-week window reward a finished *loop*, not a finished *catalogue*; a Vertical Slice that is genuinely fun plus ~6 biome pairs and 3 tiers is a credible EA launch, while a 1.0 that promises "the full game" at the same content level invites "thin" reviews. (3) Calendar: EA lets the launch land before or shortly after the baby, with the post-launch patch cadence sized to family life (ticket 53), instead of holding the release for a content-complete bar that moves. The costs are real and recorded: Next Fest is one-time and must precede the EA launch; EA launch *is* the launch for review momentum (there is no second first impression), so the EA entry bar must be high on polish and low on quantity. Henry rules in ticket 05.

## Decisions so far

- [Workshop node](tickets/14-workshop-node.md) — the party grows 1 → 2 → 3 here and only here. **The number this ticket owns: assembly costs a blueprint + 75 scrap**, derived not picked — 450 income ÷ 3 markets = 150 a visit, ÷ 2 recruits = 75, so growing the team costs exactly one market visit. That makes the run's three sinks quotable against each other: **of the three market visits a run earns, one buys the team, one strips the filler, one buys cards.** One recruit ≈ 1.6 cards' worth of shop. Reflash at 40 is flagged as a **reading** — your ruling names assembly and is silent on reflash; set the constant to 0 if you read it narrowly. Removal is priced same-as-market (your lean), because cheaper here would falsify ticket 13's derivation and make the market's button a decoy. **The dispatch ordering is a test, not a comment**: assembly writes both slices, so ranch-first vs run-first were both run against the real store and handed to `reconcileLoadedState` — ranch-first leaves you the individual and resumes the run, run-first makes the run undiscardable-but-illegal and costs forty minutes. Suite 1163 → **1235**.
- [Marketplace node](tickets/13-marketplace-node.md) — buy, sell, remove and reroll, all from the map. Numbers derived from ticket 12's anchor and **all proposals**: ~150 scrap per market visit (450 ÷ 3 markets), stock 5 + 1 off-pool wildcard, cards 24/40/64/96 by rarity +8 per energy, sell at 0.4x, reroll 20, **removal 30** — which is your stated target done as arithmetic (5 generics across a 1→2→3 run × 30 = one visit's scrap), and the test computes it from the constants so retuning them fails the test instead of quietly falsifying the comment. **"Power dies at the surface" now has a test**: price is a pure function of (rarity, energy), two cards identical but for `power` price identically, and the markup contains no `/power/i` — which cost us card descriptions on the offer row, because several of them say the number out loud. `sell < buy` for all 216 registry cards by construction. Two things `IRunState` had no field for were solved without touching it: **sold-out is derived** (offer instance ids are minted from the node seed, so an offer is sold when its id is in the deck) and **the reroll is a paid re-entry**. Suite 1107 → **1163**.
- [Rewards refit](tickets/12-rewards-refit.md) — a won fight pays **scrap, one pick-1-of-3 per defeated enemy, and maybe a blueprint**, and every number in that sentence is in one of two exported tables keyed by node kind. `totalXP` is gone from the type, so there is no slot for XP to reappear in. **Every number is a proposal awaiting you** (`BLUEPRINT_DROP_RATE`: wild/ambush 20%, elite 25%, alpha **100% — ruled**, gym 50% placeholder; `SCRAP_PER_ENEMY`: wild 8–14, ambush 10–16, elite 18–26, alpha 30–40 — a full run lands near 450–500 scrap, and ticket 13 will calibrate against it). `getBlueprintRate(rosterSize)` is **deleted**: it throttled drops by how many mingmings you own, which made sense when a blueprint was a dedup'd permission and inverts now it is currency — it would have throttled hardest on the player deepest in the grind, and turned the alpha's ruled 100% into 15%. **The blueprint is banked when it DROPS, not on the CONTINUE button** — it was component state before, so closing the app on the reward screen lost it. The last open economy item, the pick pool, ships as the designer's recommendation (the party's species pools, untagged kit cards included) behind **one function** so your ruling changes one place. Repeat fights pay full rewards, asserted four ways. Suite 1077 → **1107**.
- [Node encounter flow](tickets/11-encounter-flow.md) — **entering a node fights, and the run owns everything run-scoped.** `ranchProjection` is deleted: `state.game` IS `IRanchState` now, and cards, deck, scrap, relics and the gauntlet all moved to the run. `activeParty` left the ranch entirely — you pick a party at run start, so the species clause lives in `RunStart` and `reconcileLoadedState`. Encounters roll from **run seed + node id + visit count**, so a second visit to the same wild is genuinely a different fight; ticket 08's kit fraction landed as one knob (biome 1 = 5 kit + 3 generics, **no OS**; biome 2 = kit + OS; biome 3 = full tuned), which makes the balance corpus the LATE-run reference. Full heal between nodes turned out to be true by construction, so it is asserted rather than coded. **A latent bug worth knowing about: defeat still called `deleteSave()`, which since ticket 23 would have deleted your entire RANCH — every individual, every blueprint — on a lost biome-1 wild. Gone.** One thing needs ratifying: run fights are `enemyMode: 'CARDS'`, because a MOVES enemy is never dealt a hand and ticket 08's whole ruling would be computed and never played. Suite 1064 → **1077**.
- [Region map screen](tickets/10-region-map-screen.md) — the graph is drawn and walkable. Layout is a **pure module** (`regionLayout.ts`) because ticket 06 removed `x`/`y` from the save on purpose — position is derivable, so the fog rule is testable without a DOM. Fog got two clauses the ruling implies but does not state, both now tested: **anywhere you have stood stays revealed**, and **fog hides the KIND, never the node** (there is a test that the gym icon is off-screen on turn one).
