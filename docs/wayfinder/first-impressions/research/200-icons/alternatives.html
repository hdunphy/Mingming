200a-2 · Answers to the rest of your notes

Things that were questions, not icon swaps.

Map and Town: how are they different?They are two sets for the same nodes, and you are right that they should be one. The live map (RegionMap) draws its nodes from icons.ts (wild, rival, elite, alpha, town, gym, start). The second set on page 5 of the first sheet (nodeGlyphs.ts: R for rival, X for fight, star for elite) is only used by the design screen sheet and a test, so no player sees it. The plan: delete it and let the map and the screen sheet use the icons.ts set. That also settles the star-vs-helmet and crown-vs-bank clashes, because the map then follows whatever Elite, Alpha and Gym end up as in the main set.
Use element marks, not emojiRuled and noted. The Codex and the type chart switch from emoji to ElementMark in 200d.
Wild vs attackSame sword, but they never share a screen (the map has no stat rows; the ranch and run start have no map nodes). If you would still rather they differ, page 2 has options for either one.
Marketplace and workshopThe map no longer draws either: a town is one node (176c). They survive as the town square's Shop and Den buttons, so the Shop icon and the Den icon are what these two rows are for.
Light Stance vs Sun EaterThis is a name, not an icon, so it is outside ticket 200. I do not know which thing you mean to rename: the card Sun Devourer, the card Sun-Eater's Plunge, or Sköll's v2 Instinct Sunscorch. Tell me and I will park it in its own ticket. Light Stance keeps sun for now.
AlertAlready renamed in the game's words (labels.ts turns StableOS into Alert). Only the icon needs a new pick; options on page 3.
